Help & Overview

Prompt Tester is a powerful tool designed to help you iterate, test, and evaluate LLM prompts across different models and scenarios. It supports template-based prompt generation, automated testing, and AI-assisted evaluation.

Quick Start Guide

  • Configure API Settings: Navigate to the Settings tab to enter your OpenAI or Gemini API key and select your preferred model.
  • Create Templates: Use the LLM request, Developer prompt, or Messages tabs to define your prompt structure. Use {{ variable_name }} for dynamic content.
  • Define Variables: In the Tests tab, add global variables or test-specific variables that will be injected into your templates.
  • Manage Tests: Click Add test to create different scenarios. You can specify "Expected" answers for the judge to compare against.
  • Execute & Analyze: Click Run tests in the header. Once finished, review the results table. Click any row to see the full request and response history.
  • Persist Work: Use Save JSON to download your current setup and Load JSON to restore it later.

Template Syntax

The app uses Nunjucks for templating. You can use simple variable substitution, loops, and conditionals within your prompts.
